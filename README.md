# Zugradar

Mobile Live-Karte für Züge in der Umgebung: Gleisnetz (OpenRailwayMap), Zugpositionen und Abfahrten (Transitous), Filter nach Fern-/Regionalverkehr/S-Bahn, Zugverfolgung und gemerkte Linien.

Eine einzelne statische Seite (`index.html`), kein Build nötig. Positionen werden aus Echtzeit-Abfahrts- und Ankunftszeiten zwischen zwei Halten berechnet.

Daten: © OpenStreetMap-Mitwirkende, CARTO, OpenRailwayMap, Transitous (nicht-kommerzielle Nutzung).
